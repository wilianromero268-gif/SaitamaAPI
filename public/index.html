Ejemplos de código

Incluye tu clave como cabecera; no la escribas en código público.

Node.js

const response = await fetch(
  "https://TU-WORKER.workers.dev/api/random?min=1&max=100",
  { headers: { "x-api-key": process.env.SAITAMA_API_KEY } }
);
const data = await response.json();
console.log(data);

Python

import os
import requests

response = requests.get(
    "https://TU-WORKER.workers.dev/api/random?min=1&max=100",
    headers={"x-api-key": os.environ["SAITAMA_API_KEY"]},
    timeout=15
)
print(response.json())
